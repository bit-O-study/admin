# 미반영 관리자 작업 통합 — 2026-11-25

- 최신 메인의 서버 제어·영상 진행률·대시보드·설정 분리 구조를 유지하면서 기존 작업 폴더의 데이터 오류 처리, 인증 리다이렉트, 관리자 계정 보호, 날짜 집계와 조회 페이지네이션을 통합했다.
- 데이터 조회 실패는 0건으로 표시하지 않는다. 회원/관리자 목록, 통계, 검색, 활동 및 상태 표시에서 실패를 별도로 처리한다.
- 영상 워커의 blocked 상태는 사용자 승인 요청과 혼동하지 않도록 ‘자동 중단 · 원인 점검 필요’로 표시한다. 진행률은 검수 완료 운동 수만 사용한다.
- 원본 작업 폴더와 임시 검증 파일은 삭제하지 않았다.

## 검증

- Vitest 전체 27파일 255개 통과. 관리자 자기 권한 해제, 미가입 계정 지정, 비관리자 비밀번호 초기화와 관리자 계정 보호 회귀 검사 포함.
- ESLint src/tests 및 TypeScript --noEmit 통과.
- 로컬 webpack 컴파일·타입·정적 페이지 생성 완료. 의존성 junction 때문에 standalone 추적 범위 경고가 있고 Next 실행기의 SecurityFatalError 안내로 최종 종료 코드는 1이었다. 로컬 산출물은 배포하지 않는다.
- 배포는 기존 GitHub Actions의 독립 npm ci → 전체 테스트 → lint → build → 타입 검사 → 서버 활성화 순서가 통과해야 한다. 운영 확인은 배포 후 기록한다.
