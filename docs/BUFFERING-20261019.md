# 관리자 화면 버퍼링

- 메뉴 링크 이동과 상단 메뉴 검색 이동 중 중앙 스피너를 표시한다. 라우트 로딩 화면도 같은 컴포넌트를 사용한다.
- 180ms 이내 이동에서는 표시하지 않아 깜빡임을 줄인다. 실제 요청이나 화면 표시를 지연시키지 않는다.
- PendingLink는 body 포털을 사용해 사이드바 영역에 가려지지 않도록 한다. 스크린 리더 상태 문구와 동작 줄이기 설정을 지원한다.
- 빌드 및 단위 테스트 202개 통과. 변경 파일 린트 통과. Edge에서 실제 컴포넌트/빌드 CSS로 360px·1280px 중앙 정렬, 지연 표시, 화면 폭, 동작 줄이기 확인.
- 위 브라우저 검증은 독립 컴포넌트 검사이며 로그인 후 운영 페이지 전환 검증은 포함하지 않는다. 아직 배포하지 않았다.
